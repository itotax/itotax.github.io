主な論文

Communications Psychology（Nature Portfolio）·2024
E-contact Facilitated by Conversational Agents Reduces Interethnic Prejudice and Anxiety in Afghanistan
Sofia Sahab, Jawad Haqbeen, Rafik Hadfi, Takayuki Ito, Richard Imade, Susumu Ohnuma, Takuya Hasegawa

アフガニスタンにおいて、異なる民族の参加者が会話型AIエージェントのファシリテーションのもとでオンライン議論を行うフィールド実験を実施。参加後に民族間の偏見と不安が低減することを示し、AIが仲介するオンライン接触（e-contact）が紛争影響下の社会における和解を支援しうることを実証した論文です。

Group Decision and Negotiation·2021 2023 Gregory Kersten GDN Journal Best Paper Award
An Agent that Facilitates Crowd Discussion: A Crowd Discussion Support System based on an Automated Facilitation Agent
Takayuki Ito, Rafik Hadfi, Shota Suzuki

大規模なオンライン議論を生産的に保つ「自動ファシリテーションエージェント」を提案。議論の論点構造を読み取り、論点・アイデア・根拠の投稿を促すファシリテーション発言を自動で行います。実際の市民議論に導入された実績を持ち、AIが群衆の合意形成を支援できることを示した論文です。

IJCAI 2007·Hyderabad, India, pp. 1347–1352
Multi-issue Negotiation Protocol for Agents: Exploring Nonlinear Utility Spaces
Takayuki Ito, Mark Klein, Hiromitsu Hattori

複数の論点が相互依存し、効用が非線形になる交渉問題を対象に、従来の線形手法では扱えない状況に対応する交渉プロトコルを提案。各エージェントが自身の効用空間から高効用の領域を探索して入札し、仲介者が社会的厚生を最大化する組合せを求めます。ACAN・ANAC につながる「複雑な自動交渉」研究の出発点となった論文です。

Instantiating the Contingent Bids Model of Truthful Interdependent Value Auctions
Takayuki Ito, David Parkes

入札者の評価値が他の入札者の私的情報に依存する「相互依存価値オークション」を対象に、Contingent Bids モデルを具体的かつ計算可能なオークション設計として実現し、正直な入札が支配戦略となることを示した論文。理論モデルを実用的なメカニズム設計へ橋渡ししました。投稿553件の中から最優秀論文賞に選ばれています。

略歴

伊藤孝行は、京都大学大学院情報学研究科社会情報学専攻の教授。専門はマルチエージェントシステムと人工知能で、自動交渉、計算論的メカニズムデザイン、AI による大規模な合意形成支援を中心に研究している。AI エージェントが議論をファシリテーションするオンライン議論プラットフォーム「D-Agree」の開発を主導し、日本各地の市民議論やアフガニスタンでのフィールド実験に適用してきた。これらを「ハイパーデモクラシー」という研究構想として進めており、その構想を実現するシステムの一つとして、複数のエージェントで議論や合意形成を支援する Agentic Web Forum「X-Agree（D-AgreeX）」も実現している。近年は、LLM エージェントによる交渉・熟議・社会シミュレーションに取り組む。文部科学大臣表彰 科学技術賞（2013年・2026年）、日本学術振興会賞（2014年）、文部科学大臣表彰 若手科学者賞（2007年）、AAMAS 2006 最優秀論文賞などを受賞。
